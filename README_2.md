# Encoderinfo (Decode It!)

**Encoderinfo** — это универсальный инструментарий для кодирования, декодирования, хеширования и криптографии, реализованный в виде мобильного приложения на Flutter. Проект предназначен для работы с различными форматами представления данных, обеспечения безопасности переписки через стеганографию и обучения азбуке Морзе.

Интерфейс приложения выполнен на **казахском языке (Қазақша)** с частичным использованием английских терминов.

---

## 🛠 Технологический стек

- **Framework:** [Flutter](https://flutter.dev/) (версия SDK >= 3.11.0)
- **Language:** [Dart](https://dart.dev/)
- **Архитектура:** Сервисно-ориентированная архитектура (SOA) с использованием Service Locator (**GetIt**).
- **Хранение данных:** **SharedPreferences** для локального кэширования истории и настроек.
- **Работа с изображениями:** Пакет `image` для попиксельной манипуляции (LSB-стеганография).
- **Криптография:** Пакеты `crypto` (хеширование) и `encrypt` (AES-шифрование).
- **Аудио:** Пакет `audioplayers` для воспроизведения звуков азбуки Морзе.
- **Сетевые запросы:** Пакет `http` для получения информации об IP-адресе.

---

## 🏗 Архитектура приложения

Приложение организовано по классической многослойной структуре:

- **`lib/core/`**: Содержит конфигурацию внедрения зависимостей (`di.dart`), использующую `get_it`.
- **`lib/data/services/`**: Слой бизнес-логики и взаимодействия с внешними ресурсами.
  - `ApiService`: Интеграция с внешним API (ip-api.com).
  - `CryptoService`: Реализация алгоритмов хеширования и проверки сложности паролей.
  - `EncodingService`: Функции преобразования текста (Base64, URL, ASCII, Binary).
  - `HistoryService`: Управление историей операций с лимитом в 10 записей.
  - `MorseAudioService`: Управление воспроизведением звуковых сигналов Морзе.
- **`lib/domain/models/`**: Определения структур данных (моделей).
- **`lib/ui/`**: Слой интерфейса пользователя.
  - `screens/`: Основные экраны приложения и специализированные инструменты.
  - `theme/`: Настройка темы приложения (Material 3, DeepPurple).
  - `widgets/`: Переиспользуемые компоненты интерфейса.

## 🚀 Функциональные возможности

### 1. Кодирование и декодирование
- **Base64**: Кодирование текста в формат Base64 и обратно с автоматическим определением формата.
- **URL Encoding**: Преобразование строк в URL-безопасный формат.
- **ASCII / Binary**: Конвертация текста в десятичные коды ASCII или двоичный код (0/1).

### 2. Криптография и безопасность
- **Генератор хешей**: Поддержка алгоритмов MD5, SHA-1, SHA-256.
- **Анализ паролей**: Оценка надежности пароля (от "Өте әлсіз" до "Мықты") на основе длины и используемых символов.
- **Стеганография (LSB)**: 
  - Скрытие текстовых сообщений внутри PNG-изображений путем манипуляции младшим значащим битом (LSB) красного канала.
  - Возможность дополнительного шифрования скрытого сообщения алгоритмом **AES-CBC**.
  - Поддержка сохранения результата в файловую систему (Mobile) или скачивания через браузер (Web).

### 3. Азбука Морзе (Morse Code)
- **Переводчик**: Двусторонний перевод (Текст ↔ Морзе) с поддержкой воспроизведения.
- **Обучение**: Режим викторины для запоминания символов с отслеживанием прогресса.
- **Справочник**: Интерактивная таблица всех символов с возможностью прослушивания каждого.
- **Настройки аудио**: Регулировка скорости (WPM) и громкости.

### 4. Инструменты разработчика
- **Timestamp Converter**: Преобразование Unix-времени в понятную дату и обратно с живыми часами.
- **IP Info**: Получение детальной информации о текущем или заданном IP-адресе (страна, город, провайдер).
- **QR Tool**: Генерация QR-кодов из текста и встроенный сканер.

### 5. Graphics Lab
- **Pixel Grid**: Интерактивная сетка 8x8 для визуализации растровой графики на битовом уровне. Позволяет увидеть, как массив нулей и единиц превращается в изображение.

## 🛠 Сборка и запуск

1.  **Установка зависимостей:**
    ```bash
    flutter pub get
    ```
2.  **Запуск приложения:**
    ```bash
    flutter run
    ```
3.  **Сборка APK (Android):**
    ```bash
    flutter build apk
    ```
4.  **Сборка для Web:**
    ```bash
    flutter build web
    ```

*Примечание: Для работы функционала IP Info требуется подключение к интернету.*
