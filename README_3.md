# ENCODERINFO: ПОЛНОЕ ТЕХНИЧЕСКОЕ РУКОВОДСТВО И ДОКУМЕНТАЦИЯ

## Введение
**Encoderinfo** — это многофункциональное Flutter-приложение, представляющее собой универсальный швейцарский нож для работы с данными. Проект объединяет в себе инструменты для кодирования/декодирования, криптографические утилиты, средства работы с QR-кодами, модули стеганографии, обучения азбуке Морзе и вспомогательные инструменты разработчика.

Основная концепция проекта заключается в предоставлении единого, удобного интерфейса для решения широкого спектра задач: от простой конвертации строк до скрытой передачи сообщений в изображениях. Интерфейс локализован на казахский язык с сохранением общепринятой англоязычной технической терминологии.

---

## 1. Подробный функциональный обзор

### 1.1. Модуль кодирования и декодирования
Реализован через `EncodingService` и экран `EncodersToolScreen`. Модуль позволяет трансформировать данные между человекочитаемым текстом и машинными форматами.

*   **Base64**:
    *   Преобразование произвольных строк в формат Base64.
    *   Декодирование Base64-строк в исходный текст.
    *   **Умное определение**: Система автоматически анализирует ввод пользователя. Если строка кратна 4 символам и соответствует регулярному выражению Base64, приложение предлагает соответствующие действия.
    *   Интерактивные подсказки на уровне пользовательского интерфейса.
*   **URL Encoding**:
    *   Кодирование компонентов URL (использование `Uri.encodeComponent`) для безопасной передачи спецсимволов в веб-запросах.
    *   Декодирование URL-строк (`Uri.decodeComponent`) в исходный вид.
*   **ASCII и Binary (Двоичный код)**:
    *   **Binary**: Перевод текста в последовательность 8-битных двоичных строк и обратно.
    *   **ASCII**: Конвертация символов в их десятичные коды (через `codeUnits`) и восстановление текста из последовательности кодов.

### 1.2. Криптография и информационная безопасность
Логика сосредоточена в `CryptoService` и на экране `CryptoToolScreen`.

*   **Хеширование (Hashing)**:
    *   Поддержка алгоритмов: **MD5**, **SHA-1**, **SHA-256**.
    *   Все методы принимают строку в кодировке UTF-8 и генерируют соответствующий шестнадцатеричный (hex) отпечаток.
*   **Анализ надежности паролей**:
    *   Автоматическая проверка вводимых паролей по нескольким критериям: минимальная длина (8 символов), наличие заглавных букв, цифр и специальных символов.
    *   Визуальная классификация уровня защиты:
        *   `Өте әлсіз` (Очень слабый)
        *   `Орташа` (Средний)
        *   `Жақсы` (Хороший)
        *   `Мықты` (Сильный)
*   **Стеганография** (`SteganographyScreen`):
    *   **Скрытие данных**: Использование метода **LSB (Least Significant Bit)** для внедрения сообщения в красный канал (R) выбранного изображения.
    *   **Извлечение**: Чтение скрытых данных из модифицированных изображений.
    *   **Дополнительное шифрование**: Возможность предварительно зашифровать сообщение алгоритмом **AES-CBC**. Ключ формируется как первые 16 байт SHA-256 хеша от введенного пользователем пароля.
    *   **Сохранение результатов**: Поддержка различных платформ — использование `dart:html` для Web и `path_provider` для мобильных и десктопных версий.

### 1.3. Работа с QR и штрихкодами
Реализовано на экране `QrToolScreen`.

*   **Генерация**: Создание QR-кодов высокого качества с помощью библиотеки `QrImageView`.
*   **Сканирование**: Интеграция с `MobileScanner` для мгновенного считывания QR и штрихкодов через камеру устройства.
*   **Взаимодействие**: Быстрое копирование распознанного текста в буфер обмена и возможность поделиться результатом через системное меню (пакет `SharePlus`).
*   **Логирование**: Все операции сканирования и генерации фиксируются в локальной истории.

### 1.4. Инструменты для разработчиков (Dev Tools)
Реализовано через `DevToolScreen`, `TimestampService` и `ApiService`.

*   **Конвертер Timestamp**:
    *   Отображение текущего Unix timestamp в реальном времени.
    *   Двусторонняя конвертация: `Timestamp ↔ Дата`.
    *   Интеллектуальное распознавание формата (секунды или миллисекунды).
    *   Использование нативных системных пикеров для выбора даты и времени.
*   **Информация об IP**:
    *   Определение данных текущего IP-адреса через сервис `http://ip-api.com/json/`.
    *   Предоставляемые данные: страна, город, интернет-провайдер (ISP).
    *   Возможность ручного запроса информации по любому конкретному IP-адресу.
*   **Graphics Lab**:
    *   Специализированный инструмент `GraphicsLabScreen`.
    *   Интерактивное поле 8x8 (64 ячейки) для проектирования простых растровых структур.
    *   Генерация итогового массива бинарных значений на основе состояния ячеек (0 или 1).

### 1.5. Модуль азбуки Морзе (Morse Code)
Глубокая реализация, включающая `MorseCodeData` и `MorseAudioService`.

*   **Переводчик**:
    *   Трансляция текста в код Морзе и обратно в реальном времени.
    *   Набор быстрых примеров (chips) для тестирования.
    *   Аудио-воспроизведение сигналов с настройкой скорости (WPM) и громкости.
*   **Интерактивный справочник**:
    *   Классификация символов: алфавит, цифры, знаки пунктуации.
    *   Текстовое описание звучания каждого символа.
    *   Возможность прослушать каждый символ по отдельности.
*   **Режим обучения**:
    *   Генерация случайных символов для тренировки распознавания.
    *   Ввод ответа через специализированный интерфейс (кнопки «точка», «тире», «пробел»).
    *   Система проверки правильности и подсчета прогресса.
    *   Экспорт статистики обучения в формате CSV через буфер обмена.

### 1.6. История операций
Централизованное хранение данных через `HistoryService` и экран `HistoryScreen`.

*   **Хранение**: Использование `SharedPreferences` для сохранения последних 10 действий.
*   **Категоризация**: Автоматическая сортировка записей по типам: QR, Hash, Encode, Decode, Dev.
*   **Управление**: Функции быстрой очистки всей истории, выборочного копирования или шаринга старых записей.

## 2. Техническая архитектура

Проект следует принципам модульности и разделения интересов.

## 3. Технический долг и ограничения

В текущей версии проекта зафиксированы следующие особенности, требующие внимания при дальнейшей разработке:

1.  **Сетевая безопасность**: Запросы к IP-API осуществляются по протоколу **HTTP**, что может быть небезопасно в открытых сетях.
2.  **Криптографические упрощения**: В модуле стеганографии для алгоритма AES-CBC используется **фиксированный нулевой вектор инициализации (IV)**, что снижает стойкость шифрования при повторном использовании ключей.
3.  **Неиспользуемый код**: В файле конфигурации `pubspec.yaml` объявлены, но фактически не задействованы в логике пакеты `provider`, `google_fonts`, `permission_handler` и `gal`.
4.  **Навигация**: Экран тонкой настройки звука Морзе (`MorseSettingsScreen`) создан, но на данный момент не имеет прямой точки входа из главного меню.
5.  **Лимиты данных**: Объем локальной истории жестко ограничен 10 записями для экономии памяти и упрощения UI.

## 4. Инструкция по развертыванию

### Требования
*   Установленный Flutter SDK (версия, поддерживающая null-safety).
*   Настроенная среда для запуска (Android Studio / VS Code с эмулятором или реальным устройством).

### Запуск проекта
1.  Склонируйте репозиторий с исходным кодом.
2.  В корневой директории проекта выполните установку зависимостей:
    ```bash
    flutter pub get
    ```
3.  Запустите приложение:
    ```bash
    flutter run
    ```
